Features

Everything you need, nothing you don't

A complete toolset for day-to-day database work, without the bloat of a full IDE.

🗂️

Schema Browser

Multi-database tree — tables, views, stored procedures and functions, all lazily loaded and ready to inspect.

📊

Spreadsheet-Style Grid

Inline cell editing with dirty-tracking — only the columns you actually change get written back.

⚡️

SQL Editor

Syntax highlighting, query history, multi-statement scripts, and quick SELECT/INSERT/UPDATE/DELETE templates.

🛠️

Schema Management

Create and alter tables with a full column editor. Views, procedures, functions, triggers and events too.

📤

Export, Import & Backup

Export to CSV, JSON, SQL or Excel. Import from CSV with automatic column mapping. Full SQL dump backups.

🔒

Private by Design

Passwords live in the macOS Keychain. No accounts, no ads, no third-party trackers — your databases never leave your Mac. Anonymous usage analytics can be switched off in Settings.

Why native matters

Most cross-platform database tools ship an entire Chromium browser just to draw a table. MySQL Client is built directly on AppKit and SwiftUI — it starts instantly, uses a fraction of the memory, and feels like it belongs on your Mac, because it does.
