MySQL Client

Privacy Policy · Last updated: October 2026

Short version: MySQL Client never collects your precise location or anything about your databases (connection details, queries, results, credentials). It does send a small amount of anonymous usage data — see below — which you can turn off at any time in Settings. The only time it receives anything you typed — including a name or an email address — is when you choose to send feedback and enter them.

1. Information We Collect

To understand how the app is used and decide which languages and features to work on next, MySQL Client collects anonymous usage analytics: app opens, which features are used (e.g. Table Export, Database Backup, Table Import, running a query), and the numeric error code when an operation fails. Along with these events, we receive basic device context — a randomly generated identifier (not tied to your identity), device model, macOS version, app version, language, timezone, approximate location (country level), and the name of the network operator your connection belongs to (e.g. your internet provider), both derived from your connection. Your IP address itself is used only to look those two up and is discarded immediately — it is never stored or logged. This is sent to a server operated by the developer — never to a third party.

We do not collect:

  • Your Apple ID
  • Your name or email address — unless you choose to enter them when sending feedback (see Section 2)
  • Your precise location
  • Your IP address (used momentarily to derive country and network operator, then discarded — never stored)
  • Any connection details (host, port, username, password), query content, query results, or database content
  • Database error messages — only the numeric error code is recorded, never the server's message text, which can contain your data
  • Advertising identifiers
  • Crash reports (none are automatically uploaded)

You can disable usage analytics at any time in Settings → General → "Share anonymous usage analytics."

2. Feedback You Choose to Send

The app has a Send Feedback form (in the Help menu and the window toolbar) for ideas, suggestions, problems and bug reports. Nothing is sent unless you fill it in and press Send. When you do, the developer receives:

  • Your message and the type you picked for it (idea, problem, bug, other)
  • Your name — only if you enter one, and used only to address you in a reply
  • Your email address — only if you enter one, and used only to reply to you
  • System information — only while "Include system information" is ticked; the form shows exactly what it is: app version, macOS version, Mac model, app language, and the type and version of the database server you are connected to (for example "MySQL 8.0"). Never a host name, a user name, a password, a query, or anything from your databases
  • A feedback identifier — a random ID used only to limit how many messages one installation can send per day. It is separate from the anonymous analytics identifier, so a message (and any name or email address sent with it) cannot be connected to your usage data
  • Proof of an App Store installation — copies installed from the Mac App Store also send a record, signed by Apple, that the app was obtained there. It identifies the app, not you; it exists so that automated abuse of the form can be refused, and it is not stored

Your IP address is not stored, and no location is derived from it for feedback. Messages are stored on a server operated by the developer, are read only by the developer, are never published, and are never shared with a third party. To have a message you sent deleted, ask through the same form or on GitHub.

Sending feedback is independent of the usage-analytics setting: it happens only when you press Send, whether analytics is on or off.

3. Data Stored Locally on Your Mac

The app stores the following data exclusively on your device:

  • Connection profiles (host, port, username, database name): stored in ~/Library/Application Support/MySQLMacClient/connections.json inside the app's sandbox container
  • Passwords: stored securely in the macOS Keychain — never written to disk in plaintext
  • App preferences (theme, grid settings, editor font size): stored in the app's sandbox container
  • Anonymous analytics identifier (a randomly generated ID, not tied to your identity): stored locally so repeated events can be recognized as coming from the same installation; only sent if usage analytics is enabled
  • Feedback identifier (a separate randomly generated ID): created the first time you send feedback, and sent only with feedback

4. Network Access

The app makes outgoing TCP connections to the MySQL servers you explicitly configure, and — unless you disable it in Settings — sends the anonymous usage events described above to a first-party endpoint operated by the developer. When you press Send in the feedback form, your message goes to the same developer-operated server. No other network connections are made.

5. Third-Party Services

MySQL Client does not integrate any third-party SDKs, advertising networks, or crash reporting frameworks. The usage analytics and the feedback described above are sent to infrastructure operated directly by the developer — no third-party analytics or support provider is used.

6. Children's Privacy

This app is not directed to children under 13. The anonymous usage analytics described in Section 1 contain no personal information and cannot be used to identify any individual user.

7. Changes to This Policy

If this privacy policy changes, the updated version will be posted at this URL. The "Last updated" date at the top of this page will reflect the change.

8. Contact

Questions about this privacy policy? Use Help → Send Feedback in the app, or open an issue on GitHub.
